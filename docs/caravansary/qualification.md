This qualification covers the compiled offline profiles, not production
provider access or empirical pricing performance.

Reproduce with the pinned checkouts and headers from [INSTALL.md](../../INSTALL.md).
For a fresh isolated On1x build:

```sh
export CC=clang CXX=clang++
export FINPRED_MULIB_BUILD_DIR=build/caravansary/toolchain
export FINPRED_BUILD_DIR=build/caravansary/qualified
make mulib
make caravansary-test caravansary-market-test
make
bin/finpred selftest
```

The local build linked the same pinned Cephyr as a prebuilt
`CEPHYR_LIBRARY`; its freestanding target runtimes and shared library were
built with Clang. The On1x build uses a scoped warning allowance for known
Chomsky3 diagnostics, not a relaxation of application compiler warnings.
No GCC compiler was used to compile the toolchain or Caravansary.

Verified locally:

- `make caravansary-test`: regenerated grammar parity, frontend/metrics
  checks, legacy Python compatibility, and byte-for-byte parity for
  the legacy Riviera matrix and reports.
- `make caravansary-market-test`: typed Probe capture, candidate ranking,
  guarded pricing, chronology checks, file and grant rejection, artifact
  validation, and native jobs. The scheduled offline scrape reopened
  persistent state, executed the packaged child and committed the same
  bytes as a direct scrape.
- The Canal fixture produced a **synthetic** GBP 125.00 nightly positioning
  recommendation from three admitted physical properties. Without
  the exact comparable input, it abstained. The full prediction command
  and its child processes made no network syscalls under `strace`.
- The Joe Litty Rooms reference parsed locally, preserved the requested
  Booking profile URL as inert metadata, and produced no artifact when
  `scrape` was invoked without a matching host grant.
- Clang-only `make` and `bin/finpred selftest` passed.

W1–W6 owned the frontend, providers, discovery, pricing, persistent jobs
and CLI respectively. W7 contributed the Joe Litty Rooms reference.
Cross-review checked profile authority, provider-to-discovery provenance,
per-night versus stay-total price units, fixed sibling ownership and
scheduled artifact replay. Worker communication used private, locked
atomic writes under `/dev/shm/finpred-caravansary/`.

No live Booking or Agoda traffic was generated by qualification. No live
selectors, public rates, exclusion accuracy, demand elasticity, real
forecast error or calibration, production ACLs, shared quota enforcement,
automatic publication, or exactly-once behavior were qualified.
