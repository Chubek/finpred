# Permission-checked offline public feed evidence (@1)

This opt-in On1x host normalizes **previously saved** ECB and Eurostat material
for offline analysis. It embeds the existing normalized object in
[`dragnet.offline-feed-evidence@1`](contracts/dragnet.offline-feed-evidence@1.schema.json).
It never contacts a provider, launches a decoder, writes a store, or dispatches
financial actions. The existing offline replay and dispatch formats are unchanged.

```sh
plugins/dragnet/build-dispatch.sh "$PWD/build/offline-evidence" --offline-evidence
python3 tests/check_dragnet_offline_evidence.py
```

## Trusted host inputs (Linux)

The caller supplies read-only descriptors for regular, immutable snapshots
from a private directory or equivalent sealed inputs. As in the legacy
dispatcher, only the trusted caller selects these descriptors; this process
does not confer file confinement on an untrusted caller. Do not pass devices,
FIFOs, or snapshots that another writer can grow or change. No stdin, filename,
env var, network mode, or implicit/default grant is used.

| FD | Bytes |
| --- | --- |
| 3 | A current, independently reviewed grant (see below), at most 512 bytes |
| 4 | Trusted host's current UTC time, second precision, followed by LF |
| 5 | Existing `dragnet.feed-capture@1`, at most 512 bytes, `offline_snapshot` only |
| 6 | Raw provider body, at most 65,536 bytes |
| 7 | Offline decoder handoff regenerated by the trusted host, at most 4,096 bytes |

The grant is exactly two LF-terminated ASCII lines. The first is
`dragnet.feed-permission@1`. The second is an unquoted comma-separated row
with these ten fields, in order (this list is not a literal header):

```text
provider,purpose,cutoff,valid_from,valid_until,capture_digest,raw_digest,decode_digest,terms_ref,retention_ref
```

Only `ecb` and `eurostat` are recognized. The only purpose is `offline_analysis`.
Use second-precision UTC (`YYYY-MM-DDTHH:MM:SSZ`, years 1970–2399) with
`valid_from <= checked_at < valid_until` and `cutoff <= checked_at`.
Each digest is `blake3:` followed by 64 lowercase hex digits of the exact
corresponding bytes. Both policy references must exactly match the capture
record. Normalization retains the existing typed descriptor checks and refuses
captures not available by the exact grant cutoff. Grant, clock and capture
scope are checked before reading the raw body; a body mismatch prevents reading
the decode slot. Denials return nonzero and emit no evidence.

The evidence includes the exact grant digest, checked time, handoff digest,
and the normalized object with its raw and capture digests. It carries
`external_execution=false`, and the nested snapshot retains
`pricing_input=false`.

## Authority and limits

The grant is not a bearer credential or a signature. The trusted operator
supplies FD 3 and FD 4 outside the dataset/package boundary, checks that the
terms and current retention policy permit this exact processing, caps expiration
at the applicable retention deadline, and withholds grants when authority,
current time, applicable policy or revocation cannot be determined. A provider's
metadata, a well-formed grant string supplied by a dataset, or a digest is not
proof of provider authenticity, permission, revocation status, or a human
financial approval. Storage, sharing, deletion, durable audit, and revocation
tracking are not implemented by this host. Legacy dispatch is still available
for trusted replay and cannot produce this evidence envelope; callers that need
the check must call this host explicitly and must not fall back on denial.
